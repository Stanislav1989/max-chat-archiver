# Тексты для карточки на addons.mozilla.org

Готовые формулировки для формы «Отправить новое дополнение». Можно копировать как есть.

## Название

```
Архивация чатов в MAX
```

## Сводка (до 250 символов)

```
Сохраняет переписку чата MAX (web.max.ru) целиком — с начала доступной истории и со всеми вложениями — в один HTML-архив: сообщения, авторы, время, фото, видео и файлы.
```

## Описание

```
Архив переписки MAX — расширение для веб-версии мессенджера MAX (web.max.ru).

Что делает:
• прокручивает чат до начала доступной истории и собирает все сообщения;
• сохраняет авторов, время, разделители по дням, реакции и пересланные сообщения;
• скачивает фотографии, видео, голосовые и документы;
• складывает всё в один ZIP: chat.html (переписка в виде чата), папка files/ с вложениями и data/messages.json для обработки скриптами.

Что внутри chat.html:
• поиск по тексту, фильтр по автору и «только с файлами»;
• тёмная тема и печать;
• разделители по дням и время у каждого сообщения.

Приватность:
• всё обрабатывается локально в браузере;
• расширение не отправляет данные на сторонние серверы, не содержит аналитики и рекламы;
• архив сохраняется в папку «Загрузки» на компьютере пользователя.

Ограничения:
• нужна открытая веб-версия MAX и вход в аккаунт;
• история ограничена тем, что отдаёт сервер;
• у документов без прямой ссылки в архив попадает только имя файла.

Требуется Firefox 142 или новее, десктоп.
```

## Примечания для проверяющих

```
Расширение работает только на web.max.ru и не затрагивает другие сайты.

1. Разрешения. host_permissions на *://web.max.ru/* нужен для content script на странице веб-версии. *://*.max.ru/* и *://*.oneme.ru/* — это CDN, откуда загружаются фотографии, видео и документы чата (i.oneme.ru); без этих разрешений вложения не скачать.

2. Код. Весь код в пакете — обычный читаемый JavaScript, без минификации, обфускации, eval и удалённо загружаемых скриптов. Поэтому исходники отдельно не прилагаются.

3. Данные. Расширение ничего не собирает и не передаёт: нет аналитики и телеметрии, внешние запросы только за файлами чата с CDN MAX. Архив формируется локально в браузере и сохраняется через blob-ссылку в папку «Загрузки». В манифесте указано data_collection_permissions: none.

4. Как проверить. Открыть любой чат на web.max.ru, нажать иконку расширения на панели, затем «1. Вся история» и «2. Собрать архив». Получится ZIP с chat.html и папкой files/.

5. Ограничение. Переписка собирается из уже отрисованной страницы (у MAX бинарный WebSocket), поэтому в архив попадает то, что отдаёт сервер.
```
