# Changelog

## 1.2.1 — 2026-11-25

- Добавлено обязательное для AMO поле `browser_specific_settings.gecko.data_collection_permissions` (`required: ["none"]` — расширение ничего не собирает и не передаёт).
- `strict_min_version` поднят до 140.0: раньше AMO отклоняет манифест с этим полем.
- Сборка `.xpi` и папка `dist/package/` для подписи через `web-ext sign`.

## 1.2.0 — 2026-11-25

### Добавлено
- Точный разбор реальной разметки `web.max.ru`: `.capsuleSeparator` (дата), `.block` (сообщение), `.messageWrapper--isOut` (своё), `.bubbleContent span.text[data-message-markup]` (текст), `.meta--text` (время), `.reaction` (реакции).
- Системные плашки («Иван добавил Марию в чат») сохраняются как сообщения от «Системы».
- «Диагностика» теперь содержит срез DOM (`domSample`), список ресурсов и кадры бинарного WebSocket.
- Сборка `.xpi` без внешних зависимостей (`npm run build`), CI для GitHub Actions.

### Исправлено
- Одинаковые сообщения, отправленные в одну минуту, больше не склеивались в одно.
- Сообщения без текста (только фотографии) больше не терялись.
- На реальной разметке MAX сбор с экрана возвращал 0 сообщений.

## 1.1.0 — 2026-11-25

- Сбор переписки прямо из DOM (`dom.js`) — web.max.ru общается по бинарному WebSocket, JSON-перехвата недостаточно.
- Объединение сетевого и экранного источников, счётчики «Сеть» и «с экрана» в панели.
- Предупреждения в архиве о неполноте данных при сборе с экрана.

## 1.0.0 — 2026-11-25

- Первый выпуск: перехват `fetch`/XHR/WebSocket, разбор JSON-ответов, автопрокрутка истории, скачивание вложений, ZIP с `chat.html`, `files/` и `data/messages.json`.
